🌐 Stock en Vivo

Conecta esta app a Firebase o a GitHub (o a las dos si quieres) para poder ver el stock actualizado desde cualquier navegador, en cualquier sitio con internet. La app sigue funcionando 100% offline aunque no actives ninguna.

1️⃣ Crea tu proyecto Firebase (una sola vez, gratis)

  1. Entra a console.firebase.google.com y crea un proyecto nuevo.
  2. En el menú, entra a Realtime Database → "Crear base de datos" → elige modo de prueba (o configura reglas luego).
  3. Ve a ⚙️ Configuración del proyecto → en "Tus apps" crea una app web (icono </>).
  4. Copia el objeto firebaseConfig que te muestra (el bloque con apiKey, databaseURL, etc.) y pégalo abajo.

2️⃣ Conecta tu app

⚪ Sin conexión a Firebase (solo datos locales)

3️⃣ Ver el stock desde cualquier sitio

💡 El plan gratuito (Spark) de Firebase Realtime Database alcanza sin problema para este uso: solo se guarda un resumen del stock, no todo el historial.

1️⃣ Prepara un repositorio en GitHub (una sola vez, gratis)

  1. Entra a github.com y crea una cuenta si no tienes.
  2. Crea un repositorio nuevo (botón "New repository"). Puede ser público o privado.
  3. Ve a tu foto de perfil → Settings → Developer settings → Personal access tokens → Tokens (classic) → "Generate new token". Márcale el permiso repo.
  4. Copia ese token (solo se muestra una vez) y pégalo abajo.

2️⃣ Conecta tu app

⚪ Sin conexión a GitHub (solo datos locales)

💡 Solo se sube un resumen del stock (no el historial de movimientos), y solo cuando algo realmente cambió, para no llenar de commits el repositorio. Si el repositorio es público, cualquiera con el link puede ver el archivo; si es privado, solo se puede ver con el token.

⚠️ El token queda guardado en este dispositivo (localStorage). No lo compartas ni lo pegues en otro sitio.
